# Данные

- `synthetic/` содержит только искусственные примеры и может быть в Git.
- `raw/`, `interim/`, `processed/` игнорируются Git; туда переносятся реальные данные.
- `gold/` создаётся в промышленном контуре и не коммитится, если содержит реальные
  запросы или персональные данные.

Схема и правила разметки приведены в корневом `README.md`. Проверяйте каждый файл
командой `uv run python scripts/validate_dataset.py <file.jsonl>`.
